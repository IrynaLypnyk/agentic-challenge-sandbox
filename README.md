# Agentic Engineering Sandbox

A lightweight sandbox for exploring agentic AI architectures,
spec-driven development (SDD), and AI-assisted software engineering.

## Purpose

- Rapid prototyping of AI-powered applications.
- Experimenting with agentic workflows and LLM integration.
- Practising spec-driven development (SDD).
- Exploring AI-assisted development with Claude Code and Cursor.
- Testing, evaluation, and verification of AI-generated solutions.

## Engineering Principles

- Think before coding.
- Keep solutions simple.
- Define requirements and acceptance criteria before implementation.
- Prefer the simplest sufficient architecture.
- Make small, focused changes.
- Test and verify results.
- Never commit API keys or secrets.

## Development Approach

1. Understand the business problem.
2. Define requirements and success criteria.
3. Design the architecture.
4. Create an implementation plan.
5. Implement incrementally.
6. Test and evaluate.
7. Demonstrate the solution.
